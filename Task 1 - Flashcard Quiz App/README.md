# Flashcard Quiz App 

A beautiful, responsive, and fully interactive Flashcard Quiz Application built using Flutter. This app helps users learn Software Engineering, OOP, and computer science concepts dynamically.

## Features 
* **Interactive 10+ Cards:** Pre-loaded with core concepts like State Management, OOP, Python, and DSA.
* **Fully Functional CRUD:** Users can **Create** new cards, **Edit** existing ones, and **Delete** cards dynamically.
* **Sleek UI:** Gorgeous lavender theme with custom progress indicators, balanced navigation, and elegant card design.
* **Responsive Layout:** Works smoothly across Web (Chrome) and Windows Native platform.



## Technologies Used 
* **Flutter** (Dart)
* **Object-Oriented Programming (OOP)** concepts for clean architecture.
